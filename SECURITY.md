# Security Policy

If you discover a security issue in Livebook, please do not open a public issue
with exploit details.

## Reporting

Send a private report with:

- a description of the issue
- reproduction steps
- affected components
- any suggested mitigation

Until a dedicated security contact is published, report issues through a
private GitHub security advisory or a direct maintainer contact.

## Scope

Please include issues related to:

- authentication or authorization
- prompt or data leakage
- remote code execution
- dependency vulnerabilities with a practical impact
- exposure of secrets or sensitive contract data
